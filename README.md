# 🤖 ربات تلگرامی پایش آگهی‌های شخصی املاک دیوار (گلستان اهواز)

ربات هوشمند و غیرهم‌پوشان پایتون برای پایش مداوم آگهی‌های **شخصی** املاک دیوار در محله گلستان اهواز، با فیلتر دومرحله‌ای حذف دفاتر املاک، قالب‌بندی خوانای فارسی و پشتیبانی کامل از سناریوهای شبکه و تحریم.

---

## 🌟 ویژگی‌های کلیدی

- **🔍 پایش دقیق و مودبانه:** پایش هر ۶۰ ثانیه با جیتر تصادفی (±۵ ثانیه) بر اساس API رسمی پروتوباف دیوار، بدون نیاز به اجرای سنگین مرورگر در حالت عادی.
- **🛡 فیلتر دو‌مرحله‌ای آگهی‌های شخصی (عدم ارسال املاک):**
  1. *لایه اول (API):* ارسال پارامتر `business-type=personal` به سرور دیوار.
  2. *لایه دوم (هوشمند):* اعتبارسنجی متادیتای اختصاصی `business_ref` دیوار + تحلیل عبارات و کلمات کلیدی مربوط به دفاتر مشاور املاک.
- **⚡ تشخیص هوشمند محدوده جغرافیایی (BBox):** فیلتر محدوده نقشه و کادر جغرافیایی محله گلستان اهواز علاوه بر اسلاگ محله.
- **🔒 امنیت بالا (Stealth Mode):** پاسخ‌دهی منحصراً به شناسه عددی مجاز (`ALLOWED_USER_IDS`). هر پیام از افراد غیرمجاز بدون هیچ واکنشی نادیده گرفته و فقط لاگ می‌شود.
- **📱 قالب‌بندی شکیل فارسی:**
  - تبدیل کلیه اعداد و مبالغ به ارقام فارسی با جداکننده هزارگان (`٬`).
  - تبدیل منطقه زمانی به ساعت رسمی تهران (`Asia/Tehran`).
  - حذف فیلدهای خالی بدون کلمات مبهم مثل «نامشخص».
  - دکمه شیشه‌ای درون پیام برای هدایت مستقیم به صفحه آگهی در دیوار.
- **📊 ذخیره‌سازی مطمئن و پایدار:** استفاده از دیتابیس داخلی SQLite با حالت WAL (Write-Ahead Logging) بدون نیاز به نصب سرور جداگانه.
- **🚨 قطع‌کننده مدار (Circuit Breaker):** ارسال هشدار تلگرامی در صورت قطعی مکرر اینترنت یا سرویس و اطلاع‌رسانی خودکار پس از بازیابی، بدون اسپم کاربر.
- **🌐 سازگار با انواع سناریوهای شبکه و پروکسی:** پشتیبانی داخلی از `TELEGRAM_PROXY_URL` (پروکسی تلگرام)، `DIVAR_PROXY_URL` (پروکسی دیوار) و `TELEGRAM_API_BASE_URL` (ریورس پروکسی تلگرام).

## 🚀 راهنمای راه‌اندازی و اجرا

### پیش‌نیازها
- پایتون نسخه 3.12 یا بالاتر
- توکن ربات تلگرام از [BotFather](https://t.me/BotFather)
- شناسه عددی تلگرام شما (از طریق ربات‌هایی مثل [userinfobot](https://t.me/userinfobot))

---

### ۱. اجرای مستقیم روی سیستم شخصی (ویندوز یا مک یا لینوکس)

۱. ریپازیتوری را کلون کرده یا وارد پوشه پروژه شوید:
```bash
cd golestan_didban_bot
```

۲. یک محیط مجازی ساخته و آن را فعال کنید:
```bash
python -m venv .venv

# در ویندوز (PowerShell):
.venv\Scripts\Activate.ps1

# در لینوکس / مک:
source .venv/bin/activate
```

۳. وابستگی‌ها را نصب کنید:
```bash
pip install -e .
```

۴. فایل تنظیمات متغیرهای محیطی را آماده کنید:
```bash
# در لینوکس/مک: cp .env.example .env
# در ویندوز PowerShell:
Copy-Item .env.example .env
```

۵. فایل `.env` را باز کرده و توکن تلگرام و یوزر آی‌دی خود را وارد کنید:
```env
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ
ALLOWED_USER_IDS=123456789
```

۶. تست اولیه و خشک (Dry-Run):
```bash
python scripts/dry_run.py
```

۷. اجرای ربات:
```bash
python -m divar_bot
```

---

### ۲. اجرا روی سرور ابری Railway (دپلوی بدون دردسر)

این پروژه دارای `railway.json` و `Dockerfile` استاندارد است:
1. در داشبورد [Railway](https://railway.app)، یک پروژه جدید ایجاد کرده و ریپازیتوری گیت‌هاب خود را متصل کنید.
2. در تب **Variables** متغیرهای زیر را تعریف کنید:
   - `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام شما
   - `ALLOWED_USER_IDS`: شناسه عددی شما
   - `DIVAR_PROXY_URL`: (چون سرورهای Railway خارج از ایران هستند، در صورت محدودیت جغرافیایی دیوار، یک پروکسی HTTP/SOCKS5 ایرانی وارد کنید؛ به بخش سناریوهای شبکه در ادامه مراجعه کنید).
3. یک **Volume** در مسیر `/app/data` اضافه کنید تا دیتابیس آگهی‌های دیده‌شده در ری‌استارت‌ها حفظ شود.
4. پروژه به‌طور خودکار بیلد و اجرا می‌شود.

---

### ۳. اجرا با Docker و Docker Compose

```bash
# بیلد و بالا آوردن سرویس در پس‌زمینه
docker compose up -d --build

# مشاهده لاگ‌ها
docker compose logs -f
```

---

### ۴. اجرا با Systemd روی سرور لینوکس (VPS)

۱. پروژه را در مسیر `/opt/golestan_didban_bot` کلون کنید.
۲. فایل `.env` و `.venv` را بسازید.
۳. فایل سرویس را کپی و فعال کنید:
```bash
sudo cp deploy/systemd/divar_bot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now divar_bot.service

# بررسی وضعیت و لاگ‌ها:
sudo systemctl status divar_bot.service
journalctl -u divar_bot.service -f
```

با توجه به شرایط اینترنت ایران، ۳ سناریوی اصلی پشتیبانی می‌شود:

| سناریو | محل اجرا | دسترسی به تلگرام | دسترسی به دیوار | راهکار کانفیگ |
|---|---|---|---|---|
| **سناریوی ۱** | لپ‌تاپ خانگی (ایران) | نیازمند فیلترشکن | مستقیم | در صورت نیاز به فیلترشکن، مقدار `TELEGRAM_PROXY_URL=socks5://127.0.0.1:1080` یا مشابه آن را تنظیم کنید. |
| **سناریوی ۲** | سرور ایران (VPS) | مسدود | مستقیم | یک پروکسی خارجی برای تلگرام در `TELEGRAM_PROXY_URL` یا یک ریورس‌پروکسی در `TELEGRAM_API_BASE_URL` قرار دهید. دیوار مستقیم وصل می‌شود. |
| **سناریوی ۳** | سرور خارج / Railway | مستقیم | ممکن است مسدود باشد | تلگرام بدون پروکسی وصل می‌شود؛ برای دیوار مقدار `DIVAR_PROXY_URL=http://user:pass@iran-proxy-ip:port` را ست کنید. |

## 🤖 دستورات ربات در تلگرام

| دستور | توضیح |
|---|---|
| `/start` | شروع ارتباط و نمایش پیام راهنمای ربات |
| `/status` | وضعیت فعلی مانیتورینگ، آمار آگهی‌های ثبت‌شده و اطلاعات چرخه آخر |
| `/last` | نمایش لینک و عنوان ۵ آگهی شخصی اخیر ارسال‌شده |
| `/pause` | متوقف کردن موقت پایش آگهی‌ها (عدم ارسال پیام) |
| `/resume` | از سرگیری مجدد پایش آگهی‌ها |

## ⚙️ متغیرهای کانفیگ (`config.yaml`)

```yaml
divar:
  urls:
    - "https://divar.ir/s/ahvaz/real-estate/golestan?bbox=48.6043%2C31.2658939%2C48.6834793%2C31.3184261&business-type=personal%2C"
  use_bbox: true              # اعمال کادر نقشه گلستان برای دقت بیشتر

monitor:
  poll_interval_seconds: 60   # بازه پایش (ثانیه)
  jitter_seconds: 5           # نوسان تصادفی برای جلوگیری از الگوی رباتیک
  max_ad_age_minutes: 180     # رد کردن آگهی‌های قدیمی‌تر از این بازه (پس از قطعی طولانی)
  notify_on_first_run: 0      # تعداد ارسال در اجرای اول (۰ یعنی فقط ثبت baseline)
  max_send_per_cycle: 20      # سقف ارسال در هر چرخه

telegram:
  send_thumbnail: true        # ارسال عکس آگهی همراه با پیام
```
